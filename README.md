# YuvaIntern – Data Science Internship

This repository contains my work for the YuvaIntern Virtual Data Science Explorer Internship.

## Project
Customer Churn Prediction

## Internship Tasks

- Week 1 – Data Science Project Planning and Strategy Design
- Week 2 – Exploratory Data Analysis (EDA) and Visualization Framework Design
- Week 3 – Python-Based Machine Learning Model Development and Evaluation Plan
- Week 4 – Comprehensive Data Science Report and Insights Presentation Plan

The Week 1 and Week 2 tasks mainly focus on project planning, EDA and visualization framework design. The examples used in the reports are illustrative because no real dataset was provided for these tasks.
